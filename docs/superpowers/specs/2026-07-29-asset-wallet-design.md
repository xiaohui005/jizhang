# 资产管家与多钱包设计说明

## 目标

在现有记账应用里新增一个「资产管家」入口，用于记录负债和债权，并在首页增加第三个快捷入口。同时引入多钱包能力，支持 `钱包1`、`钱包2` 这类独立账本，每个钱包的账单、预算、资产管家和统计彼此隔离。

## 范围

### 资产管家最小可用版

- 首页新增「资产管家」入口。
- 资产管家页面显示净资产汇总。
- 资产管家页面分为「负债」和「债权」两类列表。
- 支持新增、删除条目。
- 数据本地保存，不联网。

### 多钱包

- 首次启用时仅保留一个默认钱包 `钱包1`。
- 所有现有账单、预算、资产管家数据默认归入 `钱包1`。
- 切换钱包后，账单、预算、资产管家、统计都只看当前钱包的数据。
- 先不做钱包重命名、排序、导出、共享。

## 数据规则

- 资产管家条目只记录两种类型：`debt` 和 `credit`。
- `debt` 表示负债，计入净资产时按负值处理。
- `credit` 表示债权，计入净资产时按正值处理。
- 净资产 = 债权总额 - 负债总额。
- 每条资产记录至少包含：钱包 id、类型、名称、备注、金额、创建时间、更新时间。

## 存储策略

- 继续使用本地 `sqflite`。
- 现有表结构增加钱包维度字段，或新增钱包表与资产表，保证每个查询都能按钱包过滤。
- 默认钱包 id 固定为 `wallet_default`，显示名为 `钱包1`。
- 旧数据在升级后自动归到默认钱包，不做迁移对话框。

## 页面结构

- 首页第三个快捷入口为「资产管家」。
- 资产管家页面顶部显示净资产卡片。
- 下方先展示负债列表，再展示债权列表。
- 底部或空态提供「添加资产」按钮。
- 新增页根据类型不同展示对应字段，负债和债权共用一套基础表单。

## 交互规则

- 删除条目需要二次确认。
- 切换钱包后页面即时刷新。
- 新增、删除资产后，净资产和列表同步更新。
- 默认钱包内没有任何数据时展示空态，不展示报错。

## 兼容性

- 现有账单、预算、分类、统计逻辑不变，只是在查询层加入钱包过滤。
- 不引入网络同步，不新增后台任务。
- 不调整现有图片资源。

## 验收标准

- 首页可看到「资产管家」入口。
- 可以创建至少两个钱包，且两个钱包的数据互不影响。
- 在当前钱包中新增负债和债权后，净资产数值正确变化。
- 切换钱包后只看到该钱包自己的数据。
- 旧账单和预算在默认 `钱包1` 中仍然可见。

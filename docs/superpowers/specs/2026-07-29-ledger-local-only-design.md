# 罐头记账纯本地模式规格

## 1. 目标

将当前 `ledger_flutter` 改成纯本地手动记账模式：只保留本地数据库与手动录入，不依赖短信自动记账、后台同步或任何网络发送能力。

## 2. 范围

- 保留：手动新增、编辑、删除账单，本地统计，本地分类，本地预算，本地设置。
- 移除：短信自动记账、短信权限申请、短信接收广播、短信解析、自动同步提示。
- 移除：所有网络发送与后台管控逻辑。
- 移除：应用中与线上导入、同步、分享网络相关的入口，如当前存在且依赖联网能力。

## 3. 目标行为

1. 应用启动后直接进入首页，不出现短信授权或自动同步引导。
2. 应用仅使用本地 `sqflite` 数据库存储记账数据和设置。
3. 应用不申请短信权限，不注册短信接收逻辑。
4. 应用不向任何服务器发送账单、短信内容或用户数据。
5. 应用不依赖后台常驻同步任务。

## 4. 需要删除或禁用的模块

- `SmsAutoBookkeepingService`
- `SmsReceiver`
- `SmsPlugin`
- `MainShell` 中短信自动同步相关初始化与前后台补同步逻辑
- `AndroidManifest.xml` 中短信权限与短信广播接收器
- 与短信自动记账相关的 UI 提示、开关、文案和日志

## 5. 保留的模块

- `DatabaseHelper` 和所有本地表结构
- 手动记账页面与统计页面
- 分类、预算、账单、日历、搜索等本地功能
- 本地通知若仅用于应用内部提示且不依赖网络，可保留

## 6. 验收标准

- 安装后可直接进入应用，不需要短信授权。
- `AndroidManifest.xml` 不再包含短信权限和短信广播接收器。
- 代码中不再存在短信自动记账初始化和同步调用链。
- 应用在离线环境下可完整新增、编辑、删除和查看账单。
- 代码中不再存在主动联网发送账单数据的路径。

## 7. 不做的事

- 不重构现有页面布局。
- 不改账单业务模型。
- 不新增云同步或账号体系。
- 不引入替代的后台同步方案。
